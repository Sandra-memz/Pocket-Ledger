# PocketLedger 

A Python-based personal finance tracker that helps users record
income and expenses, monitor their balance, and manage transaction
history through an interactive terminal interface.

## Features

- Record income and expenses.
- View transaction history.
- Calculate total income, expenses, and current balance.
- Search transactions by category.
- Delete transactions using their IDs.
- Save transaction data in JSON format.
- Validate user input.

## Technologies Used

- Python
- JSON
- datetime
- pathlib

### Requirements
